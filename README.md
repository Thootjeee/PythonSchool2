Met deze code kan je sensorwaarden genereren.
je kan minimale maximale en drempelwaarden in voeren en dan zal de code zich daar op aanpassen.
ook slaat de code deze gegevens op in een csv bestand en maakt 2 grafieken:
een lijngrafiek met een rechte lijn waar de drempelwaarde is.
een histogram waarin staat hoevaak bepaalde waarden voorkomen.
ook kan je met de code vorige bestanden bekijken en de nieuwe drempelwaarde invoeren.
